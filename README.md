# 勤怠管理.xlsm — 出勤・退勤ボタン付き勤務時間＆給料計算

「出勤」「退勤」ボタンを押すだけで、別タブに勤務時間を記録・自動計算するExcelファイルです。
給料は「8時間で35,000円」（時給4,375円）で計算されます。

## ファイル

- **`勤怠管理.xlsm`** … 本体。これを使います。
- `tools/` … このxlsmを生成するためのスクリプト（通常は触らなくてOK）。

## 使い方

1. `勤怠管理.xlsm` を Excel（Windows / Mac のデスクトップ版）で開きます。
2. 開いたときに黄色い警告バーが出たら **「コンテンツの有効化」** を押します（マクロを有効にする）。
3. **「打刻」タブ**で操作します。
   - 仕事を始めるとき → **「出勤」** ボタン
   - 仕事を終えたとき → **「退勤」** ボタン
4. 押すと **「勤務記録」タブ**に自動で行が追加され、次が計算されます。

| 列 | 内容 | 例 |
|----|------|-----|
| 日付 | 出勤ボタンを押した日 | 7/24 |
| 出勤 | 出勤ボタンを押した時刻 | 17:30 |
| 退勤 | 退勤ボタンを押した時刻 | 20:00 |
| 勤務時間 | 自動計算 | 2時間 30分 |
| 給料 | 自動計算（8時間=35,000円） | 10,938円 |

- 深夜をまたぐ勤務（例 22:00→翌3:00）も正しく計算されます（→ 5時間 0分）。
- 「勤務記録」タブの右側に **合計勤務時間 / 合計給料 / 時給** が表示されます。
- 単価を変えたいときは、右側の **H1セル（8時間あたりの給料）** を書き換えてください。
- 最初に入っている3行はサンプルです。不要なら削除してください。

## マクロが使えない環境について

Web版Excel・Google スプレッドシート・Mac の Numbers など、マクロ（VBA）が動かない
環境ではボタンは反応しません。その場合でも、**「勤務記録」タブの 日付・出勤・退勤 の
セルに直接入力すれば、勤務時間と給料は自動計算されます**（計算は数式で作られているため）。
時刻は `17:30` のように入力してください。
