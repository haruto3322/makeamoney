# キーフレームの読み方

## 大前提: フレームは「同一カットの時系列」

`cut_003_f1.jpg` 〜 `f4.jpg` は同じカットの先頭→末尾を等間隔にサンプリングしたもの。
**フレーム間の差分が、カメラの動きと被写体のアクションそのもの**になる。
1 枚だけ見て判断すると、カメラワークは原理的に推定できない。必ず並べて見比べる。

## カメラの動きの見分け方

| フレーム間で起きていること | 推定される動き |
|---|---|
| 画角全体が水平に平行移動、被写体の見え方(向き)は変わらない | `pan`(その場で振る)または `truck`(平行移動) |
| 被写体が大きくなり、**周辺の物体も外へ広がる**(パースが変化) | `dolly-in`(前進) |
| 被写体が大きくなるが、**背景の相対位置が変わらない**(パースが不変) | `zoom-in` |
| 背景だけが被写体の周りを回り込む | `orbit` / `arc` |
| 全体が小刻みに不規則にズレる、水平が揺れる | `handheld` |
| 滑らかに追従、水平が保たれている | `gimbal follow` / `steadicam` |
| 上下に振れて、上か下に抜ける | `tilt` |
| 何も変わらない | `static`(三脚固定) |

**dolly と zoom の区別**が最も間違えやすい。前景と背景の**相対的な大きさの比**が変われば dolly、
全体が一様に拡大していれば zoom。判断がつかないときは `slow push-in` のように
動きの向きだけを書き、断定を避ける。

## ショットサイズの目安(人物基準)

| 記号 | 画面に入る範囲 |
|---|---|
| `EWS` | 人物が点。風景・建物が主役 |
| `WS` | 全身+周囲の空間 |
| `FS` | 全身がぎりぎり収まる |
| `MS` | 腰から上 |
| `MCU` | 胸から上 |
| `CU` | 顔全体 |
| `ECU` | 目・口・手など部分 |
| `insert` | 物のアップ(商品・小物・画面) |

## 照明で見るポイント

- **方向**: 順光 / サイド / 逆光 / トップ / 底光り。顔や物の影の落ち方から判断する
- **質**: 硬い(影の境界がシャープ、コントラスト高)/ 柔らかい(影がなだらか)
- **色温度**: 暖色(タングステン・夕方)/ 中立 / 寒色(曇天・夜・蛍光灯)
- **光源**: 自然光(窓・太陽)/ プラクティカル(画面内に見える照明)/ 明らかな作り込み
- **特徴的な要素**: レンズフレア、ハレーション、リムライト、ネオンの色被り

## カラーグレードで見るポイント

- 全体の色被り(暖色/寒色/ティール&オレンジ/モノクロ寄り)
- コントラスト(低 = フィルム/フラット、高 = クリスプ)
- シャドウの持ち上げ(黒が浮いている = フィルムエミュレーション)
- 彩度(高彩度/くすんだ低彩度/特定色だけ強い)
- 粒子感・質感(グレイン、ノイズ、ソフトフォーカス、ハレーション)

## やってはいけないこと

- **画から読み取れないことを断定する**。BGM の曲名、撮影機材の型番、撮影地の固有名詞などは書かない。推測であることを明示するか、書かない
- **フレームが 1 枚しか無いカットで動きを断定する**。その場合は `static` ではなく「不明(フレーム不足)」と書くか、`camera.movement` を控えめに書く
- **全カットを同じ語彙で埋める**。カットごとに実際に違うところを見つけて書き分ける。全部が「柔らかい自然光、暖色グレード」になっていたら、ちゃんと見ていない

## 尺とプロンプトの関係

生成 AI の 1 クリップは 5〜10 秒程度が上限のことが多い。カットが長い場合はプロンプト末尾に
実尺を書いておく(`Duration about 2.6 seconds.`)。極端に長いカット(10 秒超)は、
プロンプトに「この尺を通して動きが継続する」ことを明記する。
