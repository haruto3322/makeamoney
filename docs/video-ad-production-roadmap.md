# 地元企業向け映像広告クリエイター 独立ロードマップ

企画・監督・編集をすべて一人で行う「ワンストップ型映像クリエイター」として、
地元企業を相手に食っていけるか? という問いに対する結論と、3年間の実行計画。

---

## 結論:食っていける。ただし条件付き

**「映像を作る人」ではなく「映像で地元企業の課題を解決する人」として動けば食っていける。**

- 地方は競合が少なく、東京の相場より安いが固定費も安い。月30〜60万円の売上は現実的なライン
- 逆に「言われたものを撮って編集するだけの人」は単価競争に巻き込まれて消耗する
- 成否を分けるのは撮影・編集の技術ではなく **営業と継続契約(リテイナー)の獲得**
- 企画・監督・編集を一人で完結できることは、地方では最大の武器(制作会社より速く・安く・柔軟)

### 食える人 / 食えない人の分岐点

| 食える人 | 食えない人 |
|---|---|
| 「採用に困ってますよね」と課題から入る | 「動画作れます」と手段から入る |
| 継続契約(月額)を積み上げる | 単発案件を追い続ける |
| 単価を上げる(効果で語る) | 単価を下げる(相見積りで勝とうとする) |
| 納品後の活用(広告運用・SNS)まで面倒を見る | 納品して終わり |

## 市場の現実(前提知識)

### 地元企業が映像にお金を払う理由(=案件の種類)

| 案件タイプ | 相場(地方) | 特徴 |
|---|---|---|
| 採用動画 | 20〜60万円 | **一番金になる**。人手不足の会社は採用に予算を出す |
| 会社・工場紹介 | 15〜50万円 | BtoB企業の営業ツール。単価高め |
| 商品・サービス紹介 | 10〜30万円 | ECやLP掲載用。数が出る |
| SNS縦型ショート広告 | 3〜10万円/本 | 単価は低いが**月額×本数の継続契約**にしやすい |
| YouTube運用代行 | 月10〜30万円 | 編集+企画+サムネ。安定収入の柱 |
| Web CM(地方TV・YouTube広告) | 30〜100万円 | 実績ができてから狙うゾーン |
| イベント・式典記録 | 5〜15万円 | 閑散期の埋め草。依存しない |

### 発注者は誰か

- 社長直(従業員5〜50人規模)が最多。**決裁が速い**のが地方の利点
- 地元の広告代理店・印刷会社・Web制作会社の下請け(営業不要だが単価6〜7掛け)
- 商工会議所・自治体(補助金絡みの案件。事業者向け動画は狙い目)

## 収益モデル:単発と継続の二階建て

```
月の売上目標(3年目) = 継続契約で固定費を賄い、単発で上積みする

  継続(ベース): SNS運用 月8万 × 2社 + YouTube代行 月15万 × 1社 = 31万円
  単発(上積み): 採用動画 40万 × 隔月1本                        = 20万円/月換算
  ──────────────────────────────
  月商 約50万円(年商600万円)→ 経費・税引後で手取り月30万円前後
```

**継続契約が月の固定費(生活費+事業費)を超えた時点で「食えている」状態。**
単発だけで食おうとすると、営業→制作→納品→また営業… の自転車操業になる。

## ロードマップ

### フェーズ0:準備期(0〜3ヶ月)— 「見せられる実績」を作る

まだ辞めない(副業でやる)。目標:ポートフォリオ3本。

- [ ] 機材を最小構成で揃える(下記「初期投資」参照。総額30〜50万円で十分)
- [ ] 編集環境を固める(DaVinci Resolve 無料版 or Premiere Pro)
- [ ] **知り合いの店・会社3社に無料 or 実費で制作させてもらう**
  - 条件:実名で公開してよいこと、ビフォーアフター(効果)を聞かせてもらうこと
  - ジャンルを散らす:①採用系 ②店舗紹介系 ③縦型ショート系
- [ ] ポートフォリオサイトを1枚作る(STUDIO / ペライチで十分)
- [ ] 屋号を決め、Googleビジネスプロフィール登録(「地域名+動画制作」で出るように)

**この期間のKPI:公開許可付きの実績3本。**

### フェーズ1:初案件期(3〜9ヶ月)— 最初の有償案件と営業の型作り

目標:月商10〜20万円(副業のまま)。

- [ ] 開業届を出す(青色申告承認申請も同時に)
- [ ] 価格表を作る(安売りしない。最低ラインを決める:例「撮影ありは15万円から」)
- [ ] 営業チャネルを3つ回す
  1. **紹介**:実績3社に「同じような会社を紹介してほしい」と明示的に頼む
  2. **下請け**:地元のWeb制作会社・広告代理店・印刷会社に営業(「動画部門の外注先」ポジション)
  3. **地域コミュニティ**:商工会議所の青年部・異業種交流会に顔を出す(即効性は低いが2年目に効く)
- [ ] 有償案件5本を納品。全案件で「その後どうなったか」をヒアリングして事例化
- [ ] クラウドソーシング(ココナラ等)は**相場観の勉強と場数用**と割り切る。主戦場にしない

**この期間のKPI:有償案件5本、うち紹介経由1本以上。**

### フェーズ2:独立期(9〜18ヶ月)— 継続契約の獲得と独立判断

目標:月商25〜35万円。**継続契約が月10万円を超えたら独立を判断。**

- [ ] 単発客に継続メニューを提案する型を作る
  - 「作った動画、広告に載せて回しませんか(運用月○万円)」
  - 「月2本ショートを作って投稿まで代行します(月○万円)」
- [ ] 継続契約2社獲得(ここが最大の山場。単発10本より継続2社)
- [ ] 単価を上げる:採用動画を30万円以上で受ける(効果事例で語る)
- [ ] 生活防衛資金(生活費6ヶ月分)が貯まっている+継続収入があるなら独立
- [ ] 独立後:小規模企業共済・国保・iDeCo等の手続き

**この期間のKPI:継続契約2社(月10万円以上)、平均単価20万円以上。**

### フェーズ3:安定期(18〜36ヶ月)— 月商50万円と「選ぶ側」になる

目標:月商40〜60万円を12ヶ月連続で維持。

- [ ] 継続契約を3〜4社に(それ以上は一人だと回らない。単価を上げて社数を絞る)
- [ ] 得意ジャンルに寄せる(例:「製造業の採用動画ならこの人」という地域内ポジション)
- [ ] 編集の一部を外注化(カット編集・テロップは月5万円で外注し、企画と撮影に集中)
- [ ] 値上げ:既存客への値上げ交渉 or 新規は新価格。年1回見直す
- [ ] 補助金(小規模事業者持続化補助金・事業再構築系)を使う客への提案を覚える
  → 客の実質負担が減り、単価50万円超の案件が通りやすくなる

**この期間のKPI:月商50万円×12ヶ月、紹介経由率50%以上、稼働は月20日以内。**

## 初期投資(最小構成:30〜50万円)

| 項目 | 目安 | メモ |
|---|---|---|
| カメラ(ミラーレス) | 15〜25万円 | SONY α6700 / FX30クラスで十分。フルサイズ不要 |
| レンズ | 5〜10万円 | 標準ズーム1本+明るい単焦点1本 |
| 音声(最重要) | 3〜5万円 | ワイヤレスピンマイク(DJI Mic等)。**音が悪い動画は仕事にならない** |
| 照明 | 2〜4万円 | LEDパネル2灯 |
| 三脚・ジンバル | 3〜5万円 | |
| PC | 手持ち or 20万円 | 編集が回るなら買い替え不要 |
| ソフト・サブスク | 月0〜7千円 | DaVinci無料版から。音源はArtlist等 |

**機材沼に入らないこと。** 2年目までは機材追加より営業に時間と金を使う。

## 必要スキル(技術以外が勝負)

1. **ヒアリング力**:「何を作るか」の前に「なぜ作るか(採用? 集客? 単価アップ?)」を聞き出す
2. **企画を1枚にまとめる力**:構成案・絵コンテを出せると「業者」から「パートナー」になる
3. **広告運用の基礎**:Meta広告・YouTube広告を自分で回せると継続契約が取れる
4. **見積り・契約の実務**:修正回数の上限、キャンセル規定、著作権の扱いを書面に
5. 撮影・編集技術:必要条件だが差別化要因ではない。「地方の上位2割」で足りる

## よくある失敗パターン(先回りして潰す)

- **安請け合いスパイラル**:5万円で受けた仕事の客は5万円の客しか紹介しない
- **修正地獄**:「修正2回まで、以降1回○円」を契約書に書かないと無限に削られる
- **単発疲弊**:毎月ゼロから営業。→ フェーズ2で継続契約に必ず転換する
- **機材投資で満足**:カメラを買っても売上は増えない。増やすのは訪問件数
- **ウェディング・イベント依存**:季節変動が激しく単価も上がらない。柱にしない

## 撤退ライン(決めておく)

- 独立後18ヶ月で継続契約ゼロ、または月商が12ヶ月平均で20万円未満なら、
  企業内動画担当(インハウス)への転職・複業へ切り替える。
  この経験はインハウスマーケター・動画ディレクター職でそのまま評価される。

## まとめ:3年間の数字目標

| 時期 | 月商目標 | 継続契約 | 状態 |
|---|---|---|---|
| 0〜3ヶ月 | 0円 | 0社 | 副業・実績3本作り |
| 3〜9ヶ月 | 10〜20万円 | 0〜1社 | 副業・有償案件5本 |
| 9〜18ヶ月 | 25〜35万円 | 2社 | 独立判断・実行 |
| 18〜36ヶ月 | 40〜60万円 | 3〜4社 | 安定・外注化・値上げ |

**技術は前提、営業が本体、継続契約が生命線。** この順番を間違えなければ、
地方でワンストップ型の映像クリエイターとして食っていくのは十分に現実的。
