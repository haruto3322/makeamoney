# 地元企業向け映像広告クリエイター 独立ロードマップ

> 企画・監督・編集をすべて一人で行う「ワンストップ型」として、地元企業相手に食っていくための3年計画。

## 🎯 結論

**食っていける。ただし条件付き。**

1. 「動画を作る人」ではなく **「動画で採用・集客の課題を解決する人」** として売る
2. 勝負は撮影・編集の技術ではなく **営業と継続契約(月額)**
3. 一人で完結できることは地方では最大の武器(制作会社より速い・安い・柔軟)

## 🗺️ 全体像(これだけ見ればOK)

| フェーズ | 時期 | 月商目標 | 自分の役割 | ゴール |
|:---|:---|---:|:---|:---|
| **0. 準備** | 0〜3ヶ月 | 0円 | 全部やる | 副業のまま実績3本を作る |
| **1. 初案件** | 3〜9ヶ月 | 10〜20万円 | 全部やる | 有償案件5本・営業の型を作る |
| **2. 独立** | 9〜18ヶ月 | 25〜35万円 | 全部やる | 継続契約2社 → 独立 |
| **3. 安定** | 18〜36ヶ月 | 40〜60万円 | 編集を手放す | 継続3〜4社・外注化・値上げ |
| **4. 組織化** | 3〜4年目 | 100〜150万円 | 企画・営業・品質管理のみ | ディレクター専業化・制作チーム化 |
| **5. 仕組み化** | 4〜5年目 | 200万円〜 | 経営とオーナー業 | ストック収益+第2ディレクター育成 |

**生命線は継続契約。** 継続収入が生活費を超えた時点で「食えている」状態。

フェーズ3までは「自分の時間を売る」働き方。**収益を伸ばしつつ自分が動かなくなるには、
フェーズ4以降で「他人の時間を売る → 仕組みを売る」への転換が必要**(詳細は拡張編)。

# フェーズ別の実行計画

## フェーズ0:準備期(0〜3ヶ月)

**ゴール:公開許可付きの実績3本** — まだ会社は辞めない。

- 機材を最小構成で揃える(30〜50万円。下の機材リスト参照)
- 知り合いの店・会社3社に **無料 or 実費で制作**
  - 条件:実名公開OK+効果(その後どうなったか)を聞かせてもらう
  - ジャンルを散らす:採用系/店舗紹介系/縦型ショート系
- ポートフォリオサイトを1枚作る(STUDIOやペライチで十分)
- Googleビジネスプロフィール登録(「地域名+動画制作」で出るように)

## フェーズ1:初案件期(3〜9ヶ月)

**ゴール:有償案件5本(うち紹介経由1本以上)** — まだ副業。

- 開業届+青色申告承認申請を出す
- 価格表を作る(例:「撮影ありは15万円から」。**安売りしない**)
- 営業チャネルを3つ回す:
  1. **紹介** — 実績3社に「似た会社を紹介して」と明示的に頼む
  2. **下請け** — 地元のWeb制作会社・広告代理店・印刷会社の「動画外注先」になる
  3. **地域** — 商工会議所青年部・異業種交流会(効くのは2年目)
- 全案件で納品後の効果をヒアリングして事例化

## フェーズ2:独立期(9〜18ヶ月)

**ゴール:継続契約2社(月10万円以上)→ 独立** — ここが最大の山場。

- 単発客に継続メニューを提案する:
  - 「作った動画、広告で回しませんか?」(運用 月◯万円)
  - 「月2本ショートを作って投稿まで代行します」(月◯万円)
- 採用動画を30万円以上で受ける(効果事例で語る)
- 独立の条件:**継続収入 月10万円以上+生活費6ヶ月分の貯金**

## フェーズ3:安定期(18〜36ヶ月)

**ゴール:月商50万円を12ヶ月維持・稼働月20日以内**

- 継続契約は3〜4社まで(それ以上は回らない。単価を上げて社数を絞る)
- 得意ジャンルに寄せる(例:「製造業の採用動画ならこの人」)
- カット編集・テロップを外注(月5万円)→ 自分は企画と撮影に集中
- 年1回値上げ。補助金(持続化補助金など)を使う提案で単価50万円超を通す

# 拡張編:収益を上げて「自分が動かない」体制へ(3〜5年目)

## 🪜 レバレッジの3段階

一人で作り続ける限り、月商60万円あたりで天井に当たる(時間切れ)。
その先は **何を売っているか** を段階的に入れ替える。

| 段階 | 売っているもの | 月商の天井 | 状態 |
|:---|:---|---:|:---|
| ① 労働 | 自分の時間 | 〜60万円 | フェーズ0〜3。全部自分でやる |
| ② レバレッジ | 他人の時間(外注チーム) | 〜150万円 | 自分は企画・営業・品質管理だけ |
| ③ 仕組み | ストック収益・パッケージ | 200万円〜 | 自分がいなくても回る部分を持つ |

**重要な前提:「完全に動かない」は幻想。** 営業(=信頼)と最終品質責任だけは最後まで残る。
残るものをこの2つだけに絞り込むのがこの拡張編のゴール。

## フェーズ4:組織化期(3〜4年目)— ディレクター専業になる

**ゴール:月商100〜150万円/自分の制作稼働 週2日以内**

### やること

1. **外注ネットワークを作る(雇用しない)**
   - 編集者2〜3人+カメラマン1〜2人を業務委託で確保(クラウドソーシング・専門学校・SNSで発掘)
   - 最初は小さい案件で試し、単価と品質の合う人だけ残す
2. **品質を「自分依存」から「仕組み依存」に移す**
   - 撮影チェックリスト/編集テンプレート(テロップ・色・音のルール)/納品前チェック表を文書化
   - これがないと外注のたびに自分が直すことになり、外注の意味がなくなる
3. **自分の仕事を4つに絞る**:営業・初回ヒアリング・企画(構成台本)・最終品質チェック
4. **単価も同時に上げる**(外注費を吸収するため):採用動画は50万円〜、CMは80万円〜

### 収支構造の例(採用動画 50万円の案件)

```
受注 50万円
  − 撮影外注(カメラマン1日)   6万円
  − 編集外注                  8万円
  ─────────────────
  粗利 36万円(自分の稼働:企画1日+撮影立会い1日+チェック半日)
```

**月4本回せば粗利144万円。** フェーズ3で月2本が限界だった仕事量が、関与を薄めることで倍になる。

### この段階の注意点

- **キャッシュフロー**:外注費は先払い、入金は後。運転資金を2〜3ヶ月分確保する
- **仕事が「制作」から「マネジメント」に変わる**。ここが苦痛な人はフェーズ3の高単価特化で止まるのも正解
- 外注品質のクレームは全部自分に来る。品質チェックだけは絶対に手放さない

## フェーズ5:仕組み化期(4〜5年目)— ストック収益とオーナー業

**ゴール:月商200万円〜/自分の制作稼働ほぼゼロ(営業と経営のみ)**

### 柱1:広告運用フィー(最強のストック収益)

- 制作した動画をMeta/YouTube広告で運用代行し、**広告費の20%を毎月受け取る**
- 例:月予算50万円の客×5社 → 月50万円が「制作ゼロ」で入る
- 動画制作は素材供給(フェーズ4のチームが作る)。運用レポートは月1回
- 効果が出ている限り解約されない。**最も「自分が動かない」収益**

### 柱2:採用支援パッケージ(高額リテイナー)

- 「動画を売る」のをやめて「採用の成果を売る」:動画+広告運用+改善提案のセット
- **月額20〜30万円×契約6ヶ月〜**。単発50万円の動画より、月25万×12ヶ月=300万円
- 実務はチームが回し、自分は月1回の定例と改善方針だけ

### 柱3:内製化支援・研修(知見を売る)

- 「動画を作ってあげる」の逆張り:**企業が自分で作れるように教える**(研修+機材選定+月1伴走)
- 研修50万円+伴走月10万円。稼働は月数時間
- 制作案件とカニバらない(内製するのはSNS日常投稿レベル。広告級の案件は結局発注される)

### 柱4:第2ディレクターの育成(自分の複製)

- フェーズ4で育てた外注編集者のうち1人を「企画から任せられるディレクター」に昇格
- 自分が取ってきた案件を丸ごと任せ、売上の30〜40%を渡す
- これで **営業以外の全工程から自分が抜ける**。2チーム体制なら制作キャパは維持したまま自分はゼロ稼働

### 5年目の月商イメージ

```
広告運用フィー 10万円 × 5社          =  50万円(稼働ほぼゼロ)
採用支援リテイナー 25万円 × 3社       =  75万円(チームが実務)
制作案件 粗利35万円 × 2本(任せる)    =  70万円(第2ディレクター)
内製化支援・研修                     =  15万円(月数時間)
─────────────────────
月商 約210万円/自分の稼働:営業・定例・品質チェックのみ(週2〜3日)
```

## ⚠️ 拡張編の失敗パターン

| パターン | 対策 |
|:---|:---|
| 標準化せずに外注 → 全部自分で直す羽目に | チェックリスト・テンプレを先に作ってから任せる |
| 安い外注を使って評判を落とす | 外注テストは自社案件・小型案件で。本番は合格者のみ |
| 運用スキルがないのに運用フィーを謳う | フェーズ2〜3のうちに自分の客の広告で運用経験を積んでおく |
| 固定給で雇って固定費に潰される | 5年目までは業務委託+成果報酬。雇用は最後の手段 |
| 全部を同時にやる | 柱は1本ずつ。まず運用フィー → リテイナー → 育成の順 |

## 🧠 技術より大事なスキル

1. **ヒアリング力** — 「何を作るか」の前に「なぜ作るか」を聞く
2. **企画書1枚** — 構成案を出せると「業者」から「パートナー」になる
3. **広告運用の基礎** — Meta/YouTube広告を回せると継続契約が取れる
4. **契約実務** — 修正回数の上限・キャンセル規定・著作権を書面に
5. 撮影・編集 — 必要条件だが差別化要因ではない。地方の上位2割で足りる

## ⚠️ 失敗パターン(先回りして潰す)

| パターン | 対策 |
|:---|:---|
| 安請け合いスパイラル | 5万円の客は5万円の客しか紹介しない。最低価格を守る |
| 修正地獄 | 「修正2回まで、以降有償」を契約書に書く |
| 単発疲弊 | フェーズ2で必ず継続契約に転換する |
| 機材投資で満足 | 売上を増やすのはカメラではなく訪問件数 |
| ウェディング依存 | 季節変動が激しく単価も上がらない。柱にしない |

## 🚪 撤退ライン

独立後18ヶ月で「継続契約ゼロ」または「月商12ヶ月平均20万円未満」なら、
企業内動画担当(インハウス)への転職・複業に切り替える。
この経験はインハウスマーケター・動画ディレクター職でそのまま評価される。
